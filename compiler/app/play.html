POKÉMON FIRERED · DÉKSA

How to play

  1. Bring your original FireRed ROM

    Use the unmodified English version 1.0, as a .gba file. Extract it first if it is inside a ZIP. Other languages, version 1.1 and modified ROMs are not supported. The site does not provide the original game.

  2. Create your game

    Open Build game, select your original ROM and choose a seed, or use Random. Your ROM stays on your device. If someone else is building a game, your request joins the waiting list.

    If your connection drops or you reload the page, return to Build game. Your browser remembers the request; you may need to select the original ROM again.

  3. Download and open it

    Download the finished .gba file and open it in a Game Boy Advance emulator. You do not need to apply a patch yourself.

    mGBA is available for Windows, macOS and Linux. On iPhone or iPad, Delta supports Game Boy Advance games. Use your emulator's import or open-file option.

Keep your seed

A seed determines wild Pokémon and the trainer teams you face. The same seed and game version recreate the same choices. Keep both if you want to share a run with someone else.

Keep your save

Save from the game's menu. Before changing ROMs, devices or emulators, export or back up the save file using your emulator's tools. Keep the ROM you started with alongside its save. Start a new game when changing seeds.

Do not overwrite your only copy of a save when trying a newer game version; compatibility between versions is not guaranteed.

Report a problem

Open a report on GitHub with your seed, game version, emulator, what happened and how to reproduce it. A screenshot helps. Do not attach an original ROM.
